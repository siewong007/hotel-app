## How to Add Screenshots

1. Capture the screen at 1920×1080 resolution
2. Save PNG files in this directory
3. Reference them in the main README.md
4. Update the status in this document

## Guidelines

- Use consistent browser viewport (1920×1080 recommended)
- Ensure no sensitive data is visible in screenshots
- Use the default theme (light mode)
- Keep file sizes reasonable (< 500 KB per screenshot)
- Name files descriptively with lowercase kebab-case
