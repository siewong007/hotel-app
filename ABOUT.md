About Hotel app
=================

Hotel app is a full‑stack hotel administrative panel combining a Rust backend (Axum + SQLx), a React + TypeScript frontend (Vite + MUI), and a Tauri desktop wrapper for offline/desktop usage. It provides booking and room management, guest profiles, payments and invoices, customer/company ledgers, reporting, and administrative workflows such as night audit and RBAC-protected operations.

This repository is intended as an educational / portfolio-grade project that demonstrates production-style architecture and operational workflows. It is not offered as a production-certified property management system — treat it as a starting point for experiments, extensions, and learning.
