# Code of Conduct

## Our Pledge

Contributors and maintainers of Hotel app are expected to create a respectful, inclusive, and constructive project environment. The repository should be a place where people can learn, review, and improve the software without harassment or hostility.

## Expected Behavior

- Communicate respectfully and professionally.
- Give and receive feedback in good faith.
- Focus criticism on code, documentation, design, and process rather than individuals.
- Be patient with contributors who are learning the project.
- Respect differences in experience level, background, and perspective.

## Unacceptable Behavior

- Harassment, intimidation, insults, or discriminatory comments.
- Personal attacks or repeated hostile communication.
- Publishing private information without permission.
- Deliberately disruptive behavior in issues, pull requests, or discussions.
- Any conduct that would be inappropriate in an academic or professional review setting.

## Enforcement

Maintainers may remove comments, close issues, reject pull requests, or restrict participation when behavior conflicts with this code of conduct. Enforcement should be proportionate, documented when appropriate, and focused on preserving a productive project environment.

## Reporting

If you observe behavior that violates this code of conduct, report it to the repository maintainer through a private channel when available. Include relevant links, screenshots, or context so the issue can be reviewed fairly.

## Scope

This code applies to project spaces including GitHub issues, pull requests, discussions, documentation, and any related collaboration channels.
